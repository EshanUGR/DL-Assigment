A deep learning project for predicting stock prices using Gated Recurrent Unit (GRU) neural networks. This project demonstrates time series forecasting on stock data with comprehensive evaluation and visualization.

## 📊 Project Overview

This project implements a GRU-based deep learning model to predict stock closing prices. The model uses historical price data (Open, High, Low) to forecast the next day's closing price using sequence learning.

### 🎯 Key Features
- **Data Preprocessing**: Comprehensive data cleaning and normalization
- **GRU Architecture**: Deep GRU network with dropout regularization
- **Time Series Analysis**: Sequence-based forecasting with 30-day lookback
- **Model Evaluation**: Multiple metrics and visualization
- **Next Day Prediction**: Real-time price forecasting
- **Interactive Visualizations**: Comprehensive plots and charts
